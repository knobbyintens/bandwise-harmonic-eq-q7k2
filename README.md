# Bandwise Harmonic EQ

A 10-band harmonic exciter and equalizer audio plugin for DAWs (VST3 / AU).

Topics: bandwise, harmonic, audio-plugin, exciter, music-production

This is a music production tool.  It contains no speech restoration code, no
research report, and no technical-report identifier.  The repository name only
shares the generic audio-processing words "bandwise" and "harmonic".

## Features

- per-band drive and harmonic generation
- shelving EQ with spectrum analyser
- preset browser and DAW automation

## Status

Plugin maintenance.  Issues cover host compatibility, UI scaling, and preset
import bugs.
